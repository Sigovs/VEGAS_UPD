# Vegas Auto Gallery vehicle-sourcing concept

Private visual sample. Static HTML/CSS/JavaScript. The form has no endpoint and is blocked from transmitting data by its CSP (`connect-src 'none'; form-action 'none'`). No analytics, backend, CRM, authentication, cookies, or storage integration was implemented. Browser autofill behavior remains under the visitor's control.
